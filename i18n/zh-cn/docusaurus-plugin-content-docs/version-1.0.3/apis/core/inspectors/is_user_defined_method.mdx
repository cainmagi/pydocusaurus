检查某个成员是否定义在某类中。

## 参数 {/* #arguments */}

### 输入 {/* #requires */}

| 参数 | 类型 | 必选 | <center>说明</center> |
| :-----: | :-----: | :-----: | :------ |
| `cls` | `type[Any]` | <InlineIcon icon={vsiCheckIcon}/> | 待检测的类。 |
| `method` | `Any` | <InlineIcon icon={vsiCheckIcon}/> | 待检查的方法。如果该方法被认为可能是定义在待测类中，则返回`True`。 |

### 输出 {/* #returns */}

| 参数 | 类型 | <center>说明</center> |
| :-----: | :-----: | :------ |
| `v_1` | `bool` | 布尔标记。如果给定的方法被认为是`cls`的成员，则返回`True`。 |
