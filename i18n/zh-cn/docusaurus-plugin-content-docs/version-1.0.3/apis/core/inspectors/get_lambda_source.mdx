## 参数 {/* #arguments */}

### 输入 {/* #requires */}

| 参数 | 类型 | 必选 | <center>说明</center> |
| :-----: | :-----: | :-----: | :------ |
| `func` | `Any` | <InlineIcon icon={vsiCheckIcon}/> | 可能是 lambda 表达式的函数对象。 |

### 输出 {/* #returns */}

| 参数 | 类型 | <center>说明</center> |
| :-----: | :-----: | :------ |
| `v_1` | `str` | 表达式。如果`func`并非函数，则返回`None`。 |
