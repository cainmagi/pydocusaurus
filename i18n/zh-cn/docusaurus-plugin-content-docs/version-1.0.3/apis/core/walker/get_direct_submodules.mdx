```python
v_1: list[module] = get_direct_submodules(module: ModuleType, filtered_by_all: bool = True)
```

获取直接定义于模块包下的成员子模块/子模块包。

## 参数 {/* #arguments */}

### 输入 {/* #requires */}

| 参数 | 类型 | 必选 | <center>说明</center> |
| :-----: | :-----: | :-----: | :------ |
| `module` | `ModuleType` | <InlineIcon icon={vsiCheckIcon}/> | 待分析的模块包。将会从中探知成员子模块/子模块包。 |
| `filtered_by_all` | `bool` | | 布尔标记。如果设置了，就会优先使用模块中定义的`__all__`值搜索成员。在这种情况下，凡是没有写明在`__all__`列表中的成员都会被无视。 |

### 输出 {/* #returns */}

| 参数 | 类型 | <center>说明</center> |
| :-----: | :-----: | :------ |
| `v_1` | `list[module]` | 模块对象列表，包含了直接定义在给定模块下的子模块/子模块包。如果子模块是从别的地方导入的，就不会包含在这个列表中。 |
