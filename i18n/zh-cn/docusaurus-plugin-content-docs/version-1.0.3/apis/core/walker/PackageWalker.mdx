用来迭代遍历模块包的遍历器。

通过给定某个模块包，该遍历器能穷尽其结构，访问到每个成员和嵌套模块，并将其中的 docstring 分析为结构化文字。

透过指定一个可定制的处理器，用户可以控制如何处理从模块中提取出的信息。

## 参数 {/* #arguments */}

该类未指定初始化方法。

### <IconObjType type="method"/> `walk_package` {/* #-walk_package */}

```python
self.walk_package(root_pkg: str | ModuleType, handler: ParserAbstract)
```

穷尽遍历指定的模块包。

该方法将会从模块包的根节点开始，遍历到其中所有的嵌套模块，并对所有访问到的成员调用处理器。

用户可以透过提供`handler`（信息处理器）的实现、来定制对访问到信息的处理过程。

#### 输入 {/* #requires-3 */}

| 参数 | 类型 | 必选 | <center>说明</center> |
| :-----: | :-----: | :-----: | :------ |
| `root_pkg` | `str \| ModuleType` | <InlineIcon icon={vsiCheckIcon}/> | 模块包的名称或其对应的模块对象。 |
| `handler` | `ParserAbstract` | <InlineIcon icon={vsiCheckIcon}/> | 调用在模块包所有嵌套成员上的处理器。 |
