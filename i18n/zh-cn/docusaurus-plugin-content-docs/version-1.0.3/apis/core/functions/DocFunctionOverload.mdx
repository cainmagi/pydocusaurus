```python
DocFunctionOverload(
    descr: str,
    args: list[DocArgument] = [],
    retval: list[DocArgument] = [],
    is_yield: bool = False
)
```

函数重载的 docstring 和其他基本信息。

若该数据存在与某函数中，则其将会在渲染时、覆盖掉函数默认的参数和结果。

## 字段 {/* #fields */}

| 字段 | 类型 | 必选 | <center>说明</center> |
| :-----: | :-----: | :-----: | :------ |
| `descr` | `str` | <InlineIcon icon={vsiCheckIcon}/> | 函数的描述文字。 |
| `args` | `list[DocArgument]` | |函数的输入参数列表。 |
| `retval` | `list[DocArgument]` | | 函数的返回值列表。 |
| `is_yield` | `bool` | | 布尔标记。如果为`True`，则该函数返回的是迭代器。 |

## 方法 {/* #methods */}

### <IconObjType type="method"/> `as_md_text` {/* #-as_md_text */}

```python
v_1: str = self.as_md_text(
    renderer: ProtocolComponent,
    has_descr: bool = True,
    ignore_self: bool = False,
    title: str = "Arguments",
    title_level: int = 3,
)
```

渲染为 Markdown 文字。

该渲染的内容将只包含定义在该数据模型内的函数重载数据。

#### 输入 {/* #requires */}

| 参数 | 类型 | 必选 | <center>说明</center> |
| :-----: | :-----: | :-----: | :------ |
| `renderer` | `ProtocolComponent` | <InlineIcon icon={vsiCheckIcon}/> | 用来渲染组件的渲染器。 |
| `has_descr` | `bool` | | 布尔标记。如果设置了，则会渲染该函数重载的描述文字。 |
| `ignore_self` | `bool` | | 布尔标记。如果设置了，会略过参数列表的第一个参数 (`self` 或 `cls`)。若对应的函数是某个类的普通方法或类方法，则需要设置该标记。在此情况下，结果中将不包含第一个参数。 |
| `title` | `str` | | 重载信息的标题。 |
| `title_level` | `int` | | 在渲染该重载内容时，所设置的、该重载的标题等级。 |

#### 输出 {/* #returns */}

| 参数 | 类型 | <center>说明</center> |
| :-----: | :-----: | :------ |
| `v_1` | `str` | 从函数重载渲染的 Markdown 文本。 |

### <IconObjType type="method"/> `str_v2` {/* #-str_v2 */}

```python
v_1: str = self.str_v2(parent: DocFunction)
```

渲染 V2 字符串。

所谓 v2 字符串可以描述为以下格式：

```python
ret: type = name(arg1: type1, arg2: type2 = default2, ...)
```

相比默认的字符串格式更加紧凑。

#### 输入 {/* #requires-3 */}

| 参数 | 类型 | 必选 | <center>说明</center> |
| :-----: | :-----: | :-----: | :------ |
| `parent` | `DocFunction` | <InlineIcon icon={vsiCheckIcon}/> | 包含了共享于各重载的父数据模型信息。 |

#### 输出 {/* #returns-3 */}

| 参数 | 类型 | <center>说明</center> |
| :-----: | :-----: | :------ |
| `v_1` | `str` | 格式化后的函数重载签名。 |
