```python
DocFunction(
    type: Literal["function"] = "function",
    name: str,
    descr: str,
    args: list[DocArgument] = [],
    retval: list[DocArgument] = [],
    is_yield: bool = False,
    f_type: FunctionType = FunctionType.FUNCTION,
    prefix: str = "",
    slang: str = "",
    lineno: int = 0,
    overloads: list[DocFunctionOverload] = []
)
```

函数的 docstring 和其他基本信息。

该数据类型可序列化。包含了函数的签名信息，以及对应的函数体、各参数、以及各返回值的 docstring。

## 字段 {/* #fields */}

| 字段 | 类型 | 必选 | <center>说明</center> |
| :-----: | :-----: | :-----: | :------ |
| `type` | `Literal["function"]` | | 作为文档成员的类型标识符。 |
| `name` | `str` | <InlineIcon icon={vsiCheckIcon}/> | 函数的名称。 |
| `descr` | `str` | <InlineIcon icon={vsiCheckIcon}/> | 函数的描述文字。 |
| `args` | `list[DocArgument]` | | 函数的输入参数列表。 |
| `retval` | `list[DocArgument]` | | 函数的返回值列表。 |
| `is_yield` | `bool` | | 布尔标记。如果为`True`，则该函数返回的是迭代器。 |
| `f_type` | `FunctionType` | | 作为函数的类型。 |
| `prefix` | `str` | | 可选前缀。如果设置过，则会在v2签名的函数名称前加上该前缀。 |
| `slang` | `str` | | 该函数的内部识别码。如果该函数是普通函数（`f_type`是`"function"`），则必须设置该值，以溯源该函数的源代码链接。 |
| `lineno` | `int` | | 定义了该函数的代码所在的行号。如果该行号无法确认，则设为`0`。 |
| `overloads` | `list[DocFunctionOverload]` | | 该函数的所有重载。如果设置过，则会使用其中的内容取代该函数默认的 docstring。 |

### <IconObjType type="param"/> `str_v2` {/* #-str_v2 */}

```python
str_v2: str = self.str_v2
```

渲染 V2 字符串。

所谓 v2 字符串可以描述为以下格式：

```python
ret: type = name(arg1: type1, arg2: type2 = default2, ...)
```

相比默认的字符串格式更加紧凑。
