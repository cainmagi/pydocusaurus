```python
DocOpTemplate(
    name: str,
    template: str,
    func: DocFunction,
    special: Literal["no", "yield"] = "no"
)
```

常规运算符的模板。

以运算符`len`为例，其实现可以写作：

```python
DocOpTemplate(name="len", template="{vr1}: {tr1} = len({va1})")
```

另一个例子是运算符`getitem`，也可以将其特定成已知类型：

```python
DocOpTemplate(name="getitem", template="data: DataType = value[key]")
```

## 字段 {/* #fields */}

| 字段 | 类型 | 必选 | <center>说明</center> |
| :-----: | :-----: | :-----: | :------ |
| `name` | `str` | <InlineIcon icon={vsiCheckIcon}/> | 运算符的名称（不包括下划线）。 |
| `template` | `str` | <InlineIcon icon={vsiCheckIcon}/> | 模板内容。使用`"{vr1}"`, `"{tr1}"`, `"{va1}"`, `"{ta1}"`, … 来分别代表返回值和输入参数的变量名、类型。 |
| `func` | `DocFunction` | <InlineIcon icon={vsiCheckIcon}/> | 从运算符的函数体的 docstring 解析的结果。 |
| `special` | `Literal["no", "yield"]` | | 针对运算符字符串形式的特殊渲染情形。如果未指定，则会默认使用`template`渲染字符串。 |

## 属性 {/* #properties */}

### <IconObjType type="param"/> `str_v2` {/* #-str_v2 */}

```python
str_v2: str = self.str_v2
```

渲染 V2 字符串。

所谓 v2 字符串可以描述为以下格式：

```python
template.format(
    va1=self.func.args[0].name, a1=self.func.args[0].type,
    ...
    vr1=self.func.retval[0].name, r1=self.func.retval[0].type,
    ...
)
```

相比默认的字符串格式更加紧凑。
