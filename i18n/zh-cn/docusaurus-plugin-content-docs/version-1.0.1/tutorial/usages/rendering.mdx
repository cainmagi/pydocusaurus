接下来的指南，介绍了如何将 pyDocusaurus 生成的文档文件合并入 Docusaurus 站点中。大致包含了以下要点：

- 创建一个新的 Docusaurus 站点；

- 使用 pyDocusaurus 生成文档相关的文件；

- 合并生成的文件；

- 针对已经存在的（例如分版）的文档站点，如何更新其中的内容。

## 1. 配备站点 {/* #1-site-preparation */}

使用以下命令，创建一个新的 Docusaurus 项目：

```sh
npx create-docusaurus@latest my-website classic --typescript --package-manager yarn
```

其后，进入项目目录，安装以下额外依赖项：

```sh
cd my-website
yarn add @docusaurus/plugin-content-docs @docusaurus/theme-common \
         @iconify-icons/codicon @iconify-icons/mdi @iconify-icons/octicon \
         @iconify/react docusaurus-plugin-sass sass sass-loader \
         prism-react-renderer remark-math@6 rehype-katex@7

yarn add --dev @types/node
yarn install
yarn dlx @yarnpkg/sdks vscode
```

## 3. 修改信息 {/* #3-modify-the-information */}

接下来，可以修改：

- `docusaurus.config.ts`: 包含站点元数据、主题、插件。

- `sidebars.ts`: pyDocusaurus 已经生成了一个包含完整 API 结构的侧边栏。用户需要做的是定制侧边栏的其他部分，例如教程文档的侧边栏。

## 4. 更新现存的文档站点 {/* #4-update-existing-documentation-site */}

在此情形下，不应该向已经存在的站点**直接复制（覆盖）所有文件**，这是因为有可能需要保留之前的 API 文档。

假设现在需要更新一个文档版本。建议按照以下步骤处理：

1. 先按照[官方指南<IconExternalLink/>][link-docuver]执行，特别是要运行以下命令：

   ```sh
   yarn docusaurus docs:version 1.0.0
   ```

2. 使用 pyDocusaurus 渲染并输出文档文件。

3. 删除文档站点项目中已经存在的 `./docs/apis` 目录，因为当前的 API 文档将要全部委托给 pyDocusaurus。

4. 复制新的 API 文档：

   ```sh
   cp -rf output_docs/docs/apis ./docs/apis
   ```

5. 合并新的侧边栏。

   不可以替换掉整个`sidebars.ts`。

   只应该更新属于 API 的部分：

   ```typescript
   const sidebars: SidebarsConfig = {
     // 默认情形下， Docusaurus 会按照 docs 文件夹结构自动生成侧边栏
     // tutorial: [{type: "autogenerated", dirName: "."}],

     tutorial: [
       "introduction",
       "tutorial/install",
       {...},
       "license",
     ],

     // highlight-start
     apis: [
       // 将你的新侧边栏配置复制到这里。
     ]
     // highlight-end
   }
   ```

6. 将新的 `output_docs/src/env/variables.tsx` 合并到你的站点项目中。需要增加的是以下部分:

   ```typescript
   interface EnvVariables {
     ...
     sourceVersion: {
       "main": string;
       "1.0.0": string;
       // highlight-next-line
       "2.0.0": string;  // 增加这一行
       [key: string]: any;
     }
     sourceURIs: {
       "main": {[key: string]: string};
       "v1.0.0": {[key: string]: string};
       // highlight-next-line
       "v2.0.0": {[key: string]: string};  // 增加这一行
       [key: string]: any;
     }
     ...
   }

   const variables: EnvVariables = {
     repoURL: "...",
     rawURL: "...",
     sourceVersion: {
       "main": "main",
       "1.0.0": "v1.0.0",
       // highlight-next-line
       "2.0.0": "v2.0.0",  // 这一行的值是 GitHub 上分支/tag的名字，也是sourceURIs所用的名字。
     },
     sourceURIs: {
       // highlight-start
       "v2.0.0": {
         // 将新生成的 sourceURIs.main 内容复制到这里。
       }
       // highlight-end
       "v1.0.0": {
         ".": "./__init__.py",
         ...
       },
       "main": {
         ".": "./__init__.py",
         ...
       }
     },
   };
   ```

   这一步会将你的项目中每个实体对应的源代码行号，告知给动态渲染机制。据此会自动在 API 文档页面顶端的导航条，生成通往你源码的链接。
