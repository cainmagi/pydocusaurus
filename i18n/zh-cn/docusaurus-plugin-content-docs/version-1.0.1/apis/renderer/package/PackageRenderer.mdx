```python
PackageRenderer(out_dir: str | PathLike[str], saver: SaverAbstract)
```

用来渲染文档页面的模块处理器。

针对每个模块包成员，调用该处理器、以处理其信息，渲染、并保存成对应的文档页面文件。

## 参数 {/* #arguments */}

### 输入 {/* #requires */}

| 参数 | 类型 | 必选 | <center>说明</center> |
| :-----: | :-----: | :-----: | :------ |
| `out_dir` | `str \| PathLike[str]` | <InlineIcon icon={vsiCheckIcon}/> | 用来保存输出文档的目录。 |
| `saver` | `SaverAbstract` | <InlineIcon icon={vsiCheckIcon}/> | 用来导出文件的保存器。 |
