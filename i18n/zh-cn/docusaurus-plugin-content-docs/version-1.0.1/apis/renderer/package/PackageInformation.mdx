```python
PackageInformation(
    user: str | None = None,
    package_name: str | None = None,
    sidebar: list[str | dict[str, Any]] | None = None,
    source_uris: dict[str, dict[str, str]] | None = None,
    source_versions: dict[str, str] | None = None
)
```

模块包的基本信息。所有的字段都是可选的，且可以从解析到的模块包数据中推断。

## 字段 {/* #fields */}

| 字段 | 类型 | 必选 | <center>说明</center> |
| :-----: | :-----: | :-----: | :------ |
| `user` | `str \| None` | | 仓库持有者的用户名。通常理解为 GitHub 的用户名。 |
| `package_name` | `str \| None` | | 在渲染文档时，所用的模块包的（同时也是项目的）名称。如果未指定，会自动推断该名称。 |
| `sidebar` | `list[str \| dict[str, Any]] \| None` | | 渲染 API 文档时，所用的侧边栏。如果未指定，会自动推断侧边栏结构。 |
| `source_uris` | `dict[str, dict[str, str]] \| None` | | 源代码URI列表。用来提供指向源代码的链接。如果未指定，会自动推断URI。 |
| `source_versions` | `dict[str, str] \| None` | | 从版本名称指向版本识别码的映射。版本名称用作字典`source_uris`的键，而版本识别码用来定位版本对应的链接。如果未指定，会自动从`source_uris`中推断出该映射。 |
