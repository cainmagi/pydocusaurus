检查值是否是某个模块/模块包的直接非模块成员。

## 参数 {/* #arguments */}

### 输入 {/* #requires */}

| 参数 | 类型 | 必选 | <center>说明</center> |
| :-----: | :-----: | :-----: | :------ |
| `obj` | `Any` | <InlineIcon icon={vsiCheckIcon}/> | 待检查的对象。 |
| `module` | `ModuleType` | <InlineIcon icon={vsiCheckIcon}/> | 待搜索的模块/模块包，其中可能定义了`value`。该搜索过程相对于这一给定的模块。 |

### 输出 {/* #returns */}

| 参数 | 类型 | <center>说明</center> |
| :-----: | :-----: | :------ |
| `v_1` | `bool` | 布尔标记。当且仅当`value`直接定义于`module`，返回`True`。 |
