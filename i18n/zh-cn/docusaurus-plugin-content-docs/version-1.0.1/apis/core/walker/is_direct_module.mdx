```python
v_1: bool = is_direct_module(value: ModuleType, module: ModuleType)
```

检查模块/模块包是否是另一个模块/模块包的直接成员。

## 参数 {/* #arguments */}

### 输入 {/* #requires */}

| 参数 | 类型 | 必选 | <center>说明</center> |
| :-----: | :-----: | :-----: | :------ |
| `value` | `ModuleType` | <InlineIcon icon={vsiCheckIcon}/> | 待检查的模块。 |
| `module` | `ModuleType` | <InlineIcon icon={vsiCheckIcon}/> | 待搜索的模块/模块包，其中可能导入了`value`。该搜索过程相对于这一给定的模块。 |

### 输出 {/* #returns */}

| 参数 | 类型 | <center>说明</center> |
| :-----: | :-----: | :------ |
| `v_1` | `bool` | 布尔标记。当且仅当`value`是`module`的直接子模块，返回`True`。亦即是说，`value`需要通过`from . import name`的形式导入。 |
