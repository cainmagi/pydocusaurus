```python
v_1: str = get_field_default(val_default: Any, val_default_factory: Any)
```

将给定的值格式化为可以填充为字段(`DocField`)默认值字段的字符串。

## 参数 {/* #arguments */}

### 输入 {/* #requires */}

| 参数 | 类型 | 必选 | <center>说明</center> |
| :-----: | :-----: | :-----: | :------ |
| `val_default` | `Any` | <InlineIcon icon={vsiCheckIcon}/> | 默认值的候选值。如果该值存在，优先使用它。 |
| `val_default_factory` | `Any` | <InlineIcon icon={vsiCheckIcon}/> | 默认工厂函数的候选值。如果默认值没有设置，则会尝试格式化该函数来充当默认值。 |

### 输出 {/* #returns */}

| 参数 | 类型 | <center>说明</center> |
| :-----: | :-----: | :------ |
| `v_1` | `str` | <p>可填充于字段默认值的字符串值。</p><p>若该值为空，表明对应的字段不存在默认值设置。</p> |
