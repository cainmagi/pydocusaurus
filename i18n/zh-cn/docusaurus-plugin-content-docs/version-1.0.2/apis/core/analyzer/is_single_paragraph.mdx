检查 Markdown 文字是否仅仅包含一个单独的段落。

## 参数 {/* #arguments */}

### 输入 {/* #requires */}

| 参数 | 类型 | 必选 | <center>说明</center> |
| :-----: | :-----: | :-----: | :------ |
| `md` | `MarkdownIt` | <InlineIcon icon={vsiCheckIcon}/> | markdown-it 解析器。 |
| `text` | `str` | <InlineIcon icon={vsiCheckIcon}/> | 要分析的文字。 |

### 输出 {/* #returns */}

| 参数 | 类型 | <center>说明</center> |
| :-----: | :-----: | :------ |
| `v_1` | `bool` | 布尔标记。如果为`True`，则所提供的`text`只包含一个 Markdown 段落。 |
