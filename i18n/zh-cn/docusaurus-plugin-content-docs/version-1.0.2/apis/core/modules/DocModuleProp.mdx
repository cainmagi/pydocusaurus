    type: Literal["package", "module", "class", "func", "type"] = "package",

针对模块的成员的 docstring 和基本信息生成的摘要。

## 字段 {/* #fields */}

<div className="long-type-table">

| 字段 | 类型 | 必选 | <center>说明</center> |
| :-----: | :-----: | :-----: | :------ |
| `name` | `str` | <InlineIcon icon={vsiCheckIcon}/> | 模块成员的名称。 |
| `descr` | `str` | | 模块成员的描述文字，亦即，该成员的 docstring。 |
| `type` | `Literal["package", "module", "class", "func", "type"]` | | 模块成员的类别。 |
| `slang` | `str` | | 模块成员的内部识别码。 |

</div>
