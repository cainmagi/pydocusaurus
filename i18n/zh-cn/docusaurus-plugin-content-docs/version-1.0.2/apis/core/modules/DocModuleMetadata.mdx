## 字段 {/* #fields */}

| 字段 | 类型 | 必选 | <center>说明</center> |
| :-----: | :-----: | :-----: | :------ |
| `title` | `str` | | 模块标题。 |
| `author` | `str` | | 在 docstring 中的作者章节。 |
| `license` | `str` | | 在 docstring 中的协议章节。 |
| `descr` | `str` | | 在 docstring 中的描述文字。 |
