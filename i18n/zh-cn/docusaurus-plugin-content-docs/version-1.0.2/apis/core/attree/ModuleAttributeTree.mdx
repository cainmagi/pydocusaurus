```python
ModuleAttributeTree(
    walk_method: Callable[[str, dict[str, Any], list[T]], T], root_name: str = "."
)
```

模块或模块包的成员属性树。

该树重构了一个完整模块包中各级成员的树状结构，并且可以转换成序列化后的字典/列表。

______________________________________________________________________

### <IconObjType type="method"/> `serialize_unpacked` {/* #-serialize_unpacked */}

```python
v_1: list[T] = self.serialize_unpacked()
```

将整棵树从根节点开始完全序列化，但是将根节点解包成包含自身（定义为空节点）的列

不同于`self.serialize()`，该方法将根节点视作一个没有子成员的叶子节点，并将根节点实际的全部子成员视作根节点的同级分支。因此，所返回的结果永远是一个列表。

#### 输出 {/* #returns-1 */}

| 参数 | 类型 | <center>说明</center> |
| :-----: | :-----: | :------ |
| `v_1` | `list[T]` | 包含了序列化后节点的列表。 |
