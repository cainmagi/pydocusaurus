```python
v_1: str = ts_object(value: Any, indent: int = 2, base_indent: int = 0)
```

将值导出为 json，并将其置入一个 typescript 对象中。

:::info

这是一个定制的 Jinja2 模板过滤器。

:::

## 参数 {/* #arguments */}

### 输入 {/* #requires */}

| 参数 | 类型 | 必选 | <center>说明</center> |
| :-----: | :-----: | :-----: | :------ |
| `value` | `Any` | <InlineIcon icon={vsiCheckIcon}/> | 待过滤的值。 |
| `indent` | `int` | | 所导出 json 的缩进。 |
| `base_indent` | `int` | | 当前位置的缩进。当对象需要放置在一个已经存在缩进的位置时，需要设置该值与当前缩进一致。 |

### 输出 {/* #returns */}

| 参数 | 类型 | <center>说明</center> |
| :-----: | :-----: | :------ |
| `v_1` | `str` | 所渲染的多行 typescript 对象数据。 |
