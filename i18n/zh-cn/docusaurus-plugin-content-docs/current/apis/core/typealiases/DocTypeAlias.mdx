类型别名的 docstring。

## 字段 {/* #fields */}

| 字段 | 类型 | 必选 | <center>说明</center> |
| :-----: | :-----: | :-----: | :------ |
| `type` | `Literal["alias"]` | | 作为文档成员的类型标识符。 |
| `name` | `str` | <InlineIcon icon={vsiCheckIcon}/> | 类型别名的名称。 |
| `definition` | `str` | <InlineIcon icon={vsiCheckIcon}/> | 类型别名的完整声明。它通常是一段赋值语句。 |
| `descr` | `str` | | 类型别名的描述文字，通常定义在代码中。 |
| `slang` | `str` | | 该类型别名的内部识别码。 |
| `lineno` | `int` | | 定义了该类型别名的代码所在的行号。如果该行号无法确认，则设为`0`。 |

### <IconObjType type="param"/> `str_v2` {/* #-str_v2 */}

```python
str_v2: str = self.str_v2
```

渲染 V2 字符串。

所谓 v2 字符串可以描述为以下格式：

```python
type Alias = TypeA | TypeB
```

注意，此处的v2字符串和类型别名在源代码中的定义式完全一致。且同样与默认的字符串完全一致。
