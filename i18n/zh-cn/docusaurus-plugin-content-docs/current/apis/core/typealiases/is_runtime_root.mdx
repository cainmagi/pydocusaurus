检查某个`ast.Node`是否定义于某个已知的运行时根模块。

该方法用来在模块中搜索类型别名的时候，排除掉那些使用`getitem`定义的全局变量，例如`os.environ[...]`。

## 参数 {/* #arguments */}

### 输入 {/* #requires */}

| 参数 | 类型 | 必选 | <center>说明</center> |
| :-----: | :-----: | :-----: | :------ |
| `node` | `AST` | <InlineIcon icon={vsiCheckIcon}/> | 待检查的`ast`节点。 |

### 输出 {/* #returns */}

| 参数 | 类型 | <center>说明</center> |
| :-----: | :-----: | :------ |
| `v_1` | `TypeGuard[Name]` | 布尔标记。如果节点来源于`os`, `sys`或是其他全局模块，则返回`True`。 |
