解析函数的 docstring。

## 参数 {/* #arguments */}

### 输入 {/* #requires */}

| 参数 | 类型 | 必选 | <center>说明</center> |
| :-----: | :-----: | :-----: | :------ |
| `func` | `Any` | <InlineIcon icon={vsiCheckIcon}/> | 待解析的函数对象。可以是普通函数或方法。 |
| `base_cls` | `type[Any] \| None` | | 可选基准类。如果提供了，就会基于给定的`base_cls`检查`func`是否是该类的成员和方法。 |

### 输出 {/* #returns */}

| 参数 | 类型 | <center>说明</center> |
| :-----: | :-----: | :------ |
| `v_1` | `DocFunction` | 从函数/方法解析后的 docstring。 |
