```python
v_1: bool = is_multival_tuple(anno: Any)
```

检查给定的类型标注是否是一个定长多值元组，其形式类似如下情形：

```python
tuple[int, str]
```

注意，形如`tuple[int]`和`tuple[int, ...]`的混淆情形将会被排除。

### 输入 {/* #requires */}

| :-----: | :-----: | :-----: | :------ |
| `anno` | `Any` | <InlineIcon icon={vsiCheckIcon}/> | 待检查的类型标注。 |

### 输出 {/* #returns */}

| 参数 | 类型 | <center>说明</center> |
