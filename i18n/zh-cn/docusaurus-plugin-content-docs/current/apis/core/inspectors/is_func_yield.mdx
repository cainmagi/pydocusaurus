检查给定的对象是否是一个返回迭代器的函数。

优先检查函数的运行时实现。如果未能检测到，再检查函数返回值的类型标注。

## 参数 {/* #arguments */}

### 输入 {/* #requires */}

| 参数 | 类型 | 必选 | <center>说明</center> |
| :-----: | :-----: | :-----: | :------ |
| `func` | `Any` | <InlineIcon icon={vsiCheckIcon}/> | 待检查的候选函数对象。 |

### 输出 {/* #returns */}

| 参数 | 类型 | <center>说明</center> |
| :-----: | :-----: | :------ |
| `v_1` | `bool` | 布尔标记。如果函数返回了生成器/迭代器，则该值为`True`。 |
