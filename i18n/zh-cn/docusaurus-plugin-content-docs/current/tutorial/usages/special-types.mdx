以下是目前支持的数据类型。不同类型的数据将会按照类型、渲染成具有对应样式的文档页面。速览以下范例页面，将能帮助读者快速了解 pyDocusaurus 如何运作。

:::tip

本站点的所有 API 文档均生成自 pyDocusaurus。以下列表展示了各种 Python 数据类型对应的文档页面代表性范例。其内容展示了当前版本的实际运行效果。

:::
