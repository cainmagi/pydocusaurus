The docstring and basic information of a class.

This serializable data type contains the parsed docstrings of the class body, the initialization function, the properties, the methods, and the overloaded operators.

## Fields

| Name | Type | Required | <center>Description</center> |
| :-----: | :-----: | :-----: | :------ |
| `type` | `Literal["typeddict"]` | | The identifier of this documentation item. |
| `name` | `str` | <InlineIcon icon={vsiCheckIcon}/> | The name of the class. |
| `descr` | `str` | <InlineIcon icon={vsiCheckIcon}/> | The description body of the class. |
| `dict_items` | `list[DocTypedDictItem]` | | The key-val items of the typed dictionary. |
| `slang` | `str` | | The internal code identifying this function. It needs to be specified when the function is a vanilla function (`f_type` is `"function"`) to provide the identification of the source code. |
| `lineno` | `int` | | The line number where the typed dictionary is defined. If the number is unknown, this value will be `0`. |
