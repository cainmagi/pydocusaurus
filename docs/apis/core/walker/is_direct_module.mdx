Check whether a module/package is a direct member of another module/package.

## Arguments

### Requires

| Name | Type | Required | <center>Description</center> |
| :-----: | :-----: | :-----: | :------ |
| `value` | `ModuleType` | <InlineIcon icon={vsiCheckIcon}/> | The module to be checked. |
| `module` | `ModuleType` | <InlineIcon icon={vsiCheckIcon}/> | The module/package where `value` is potentially imported. The detection is related to this module. |

### Returns

| Name | Type | <center>Description</center> |
| :-----: | :-----: | :------ |
| `v_1` | `bool` | A flag. It is `True` only if `value` is a direct member imported via `from . import name`. That means exactly one level deeper. |
