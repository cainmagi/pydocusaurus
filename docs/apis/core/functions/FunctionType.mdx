Get the method type validator for a specific class.

#### Requires

| Name | Type | Required | <center>Description</center> |
| :-----: | :-----: | :-----: | :------ |
| `base_cls` | `type[Any] \| None` | <InlineIcon icon={vsiCheckIcon}/> | The base class use for producing the parameter. This base class needs to be used when the function is viewed as method candidates which are checked under a class scope. If not provided, this validator will only verify whether an object is a function. |

#### Returns

| Name | Type | <center>Description</center> |
| :-----: | :-----: | :------ |
| `v_1` | `Callable[[Any], Self \| None]` | A function validating the function type of the given object. If it is not callable or not a function, return `None`. |
