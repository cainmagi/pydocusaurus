The temporary abstract attributes of a class.

This collection will be available when a temporary class profile is abstract.

## Fields

| Name | Type | Required | <center>Description</center> |
| :-----: | :-----: | :-----: | :------ |
| `properties` | `list[property \| cached_property]` | | All abstract properties of this class. |
| `methods` | `list[function \| classmethod \| staticmethod]` | | All abstract instance/class/static methods of this class. |
| `operators` | `dict[str, function]` | | All overloaded abstract operators of this class. |
