Check whether a member is defined in a class.

## Arguments

### Requires

| Name | Type | Required | <center>Description</center> |
| :-----: | :-----: | :-----: | :------ |
| `cls` | `type[Any]` | <InlineIcon icon={vsiCheckIcon}/> | The class to be inspected. |
| `method` | `Any` | <InlineIcon icon={vsiCheckIcon}/> | A method to be checked. It will be marked as `True` is it is detected to be possibly defined in the given class. |

### Returns

| Name | Type | <center>Description</center> |
| :-----: | :-----: | :------ |
| `v_1` | `bool` | A flag. If `True`, the method is thought to be a member of `cls`. |
