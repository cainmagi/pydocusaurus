Solve the relative path.

## Arguments

### Requires

| Name | Type | Required | <center>Description</center> |
| :-----: | :-----: | :-----: | :------ |
| `path_from` | `str` | <InlineIcon icon={vsiCheckIcon}/> | An anchor path. The final path is solved starting from this path. |
| `path_to` | `str` | <InlineIcon icon={vsiCheckIcon}/> | The target path. |

### Returns

| Name | Type | <center>Description</center> |
| :-----: | :-----: | :------ |
| `v_1` | `str` | The relative path from `path_from` to `to_ppath_toath`, always using forward slashes for URL compatibility. |
