Convert the package name as a PyPI name.

This is a customized Jinja2 template filter.

## Arguments

### Requires

| Name | Type | Required | <center>Description</center> |
| :-----: | :-----: | :-----: | :------ |
| `value` | `Any` | <InlineIcon icon={vsiCheckIcon}/> | The value to be filtered. It supposes to be a `str`. |

### Returns

| Name | Type | <center>Description</center> |
| :-----: | :-----: | :------ |
| `v_1` | `str` | The normalized name. The space and underline symbols will be converted to the connection dash. |
