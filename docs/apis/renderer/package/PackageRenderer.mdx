```python
PackageRenderer(out_dir: str | PathLike[str], saver: SaverAbstract)
```

This is an abstract class requiring further implementation.

The module parser implemented for rendering documentation pages.

This renderer will be called on each package member and save the parsed information as a documentation page file.

## Arguments

### Requires

| Name | Type | Required | <center>Description</center> |
| :-----: | :-----: | :-----: | :------ |
| `out_dir` | `str \| PathLike[str]` | <InlineIcon icon={vsiCheckIcon}/> | The output directory where the documentation is saved. |
| `saver` | `SaverAbstract` | <InlineIcon icon={vsiCheckIcon}/> | The saver used for dumping the files. |
