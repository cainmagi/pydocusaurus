### <IconObjType type="method"/> `icon_obj`

```python
v_1: str = self.icon_obj(
    type: Literal[
        "method", "op", "param", "package", "module", "class", "func", "type"
    ],
    text: str = "",
)
```

The protocol of the subtitle icon.

#### Requires

| Name | Type | Required | <center>Description</center> |
| :-----: | :-----: | :-----: | :------ |
| `type` | `Literal["method", "op", "param", "package", "module", "class", "func", "type"]` | <InlineIcon icon={vsiCheckIcon}/> | The name determining the icon. |
| `text` | `str` | | An optional text after the icon. If it is empty, will only display the icon. |

#### Returns

| Name | Type | <center>Description</center> |
| :-----: | :-----: | :------ |
| `v_1` | `str` | The MDX code of the icon-text. |
