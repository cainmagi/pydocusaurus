
Attempt to get the signature of a potential function.

## Arguments

### Requires

| Name | Type | Required | <center>Description</center> |
| :-----: | :-----: | :-----: | :------ |
| `func_candidate` | `Any` | <InlineIcon icon={vsiCheckIcon}/> | An object that is callable and able to provide a function signature. |

### Returns

| Name | Type | <center>Description</center> |
| :-----: | :-----: | :------ |
| `v_1` | `Signature` | <p>If the <code>func_candidate</code> is already a function, get its signature directly.</p><p>Otherwise, get its equivalent callable signature (such as init method of a class).</p> |
