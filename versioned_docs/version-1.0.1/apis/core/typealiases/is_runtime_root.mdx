Check whether an `ast.Node` is specified by a known run-time root.

This method is used for excluding global variables defined by `getitem` method such as `os.environ[...]`.

## Arguments

### Requires

| Name | Type | Required | <center>Description</center> |
| :-----: | :-----: | :-----: | :------ |
| `node` | `AST` | <InlineIcon icon={vsiCheckIcon}/> | The `ast` node to be checked. |

### Returns

| Name | Type | <center>Description</center> |
| :-----: | :-----: | :------ |
| `v_1` | `TypeGuard[Name]` | A flag. It is `True` if it is provided by `os`, `sys`, and some other global modules. |
