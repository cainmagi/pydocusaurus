Parse the docstring of all type aliases defined in a module.

## Arguments

### Requires

| Name | Type | Required | <center>Description</center> |
| :-----: | :-----: | :-----: | :------ |
| `obj` | `Any` | <InlineIcon icon={vsiCheckIcon}/> | The place where the attributes will be checked for detecting the type aliases. In most cases, this value should be a module. |

### Returns

| Name | Type | <center>Description</center> |
| :-----: | :-----: | :------ |
| `v_1` | `list[DocTypeAlias]` | The parsed docstrings of the type aliases. Note that these results are purely inferred from the codes. The members are not guaranteed to be type aliases. Extra run-time checks need to be done to secure results. |
