The docstring and basic information of a protocol (typing class).

The protocol is a specialized abstract class. However, it does not provide functionalities in run time but only used during the type checking. The serialized information is rendered differenly compared to regular classes.

| `lineno` | `int` | | The line number where the class is defined. If the number is unknown, this value will be `0`. |
