Check whether an `ast.Node` is specified by a function call of `TypeVar` and `ParamSpec`.

This method is used for excluding the generic types defined in a module.

## Arguments

### Requires

| Name | Type | Required | <center>Description</center> |
| :-----: | :-----: | :-----: | :------ |
| `value` | `AST` | <InlineIcon icon={vsiCheckIcon}/> | The `ast` node to be checked. |

### Returns

| Name | Type | <center>Description</center> |
| :-----: | :-----: | :------ |
| `v_1` | `TypeGuard[Call]` | A flag. It is `True` if RHS is a `TypeVar`/`ParamSpec`/etc. call. |
