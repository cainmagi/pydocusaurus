Get the source definition of a lambda function expression.

## Arguments

### Requires

| Name | Type | Required | <center>Description</center> |
| :-----: | :-----: | :-----: | :------ |
| `func` | `Any` | <InlineIcon icon={vsiCheckIcon}/> | A function object that is potentially a lambda function. |

### Returns

| Name | Type | <center>Description</center> |
| :-----: | :-----: | :------ |
| `v_1` | `str` | The expression. Will return `None` if the given `func` is not a lambda function. |
