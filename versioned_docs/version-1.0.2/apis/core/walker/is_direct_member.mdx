Check whether a value is a direct member of another module/package.

## Arguments

### Requires

| Name | Type | Required | <center>Description</center> |
| :-----: | :-----: | :-----: | :------ |
| `value` | `Any` | <InlineIcon icon={vsiCheckIcon}/> | The value to be checked. It can be a module/package or just a plain value. |
| `module` | `ModuleType` | <InlineIcon icon={vsiCheckIcon}/> | The module/package where `value` potentially exists. The detection is related to this module. |

### Returns

| Name | Type | <center>Description</center> |
| :-----: | :-----: | :------ |
| `v_1` | `bool` | A flag. It is `True` only if `value` is a direct member defined or imported in `module`. |
