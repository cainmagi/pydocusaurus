Import a package by its name.

## Arguments

### Requires

| Name | Type | Required | <center>Description</center> |
| :-----: | :-----: | :-----: | :------ |
| `module` | `ModuleType \| str` | <InlineIcon icon={vsiCheckIcon}/> | The package to be imported. It can be an already imported package. |

### Returns

| Name | Type | <center>Description</center> |
| :-----: | :-----: | :------ |
| `v_1` | `module` | The imported package. It is the input value if the input value is already imported. |
