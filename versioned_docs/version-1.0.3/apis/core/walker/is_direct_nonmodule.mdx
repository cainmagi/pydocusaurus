Check whether a non-module object is directly defined in a module/package.

## Arguments

### Requires

| Name | Type | Required | <center>Description</center> |
| :-----: | :-----: | :-----: | :------ |
| `obj` | `Any` | <InlineIcon icon={vsiCheckIcon}/> | An object to be checked. |
| `module` | `ModuleType` | <InlineIcon icon={vsiCheckIcon}/> | The module/package where `obj` is potentially defined. The detection is related to this module. |

### Returns

| Name | Type | <center>Description</center> |
| :-----: | :-----: | :------ |
| `v_1` | `bool` | A flag. If it is `True`, it means the `obj` is directly defined in `module`. |
