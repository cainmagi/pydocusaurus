Check whether a module is a `__main__` module.

A `__main__` module is the entrypoint of a package.

## Arguments

### Requires

| Name | Type | Required | <center>Description</center> |
| :-----: | :-----: | :-----: | :------ |
| `module` | `ModuleType` | <InlineIcon icon={vsiCheckIcon}/> | The module to be checked. |

### Returns

| Name | Type | <center>Description</center> |
| :-----: | :-----: | :------ |
| `v_1` | `bool` | A flag that is `True` if `module` is the `__main__` module. |
