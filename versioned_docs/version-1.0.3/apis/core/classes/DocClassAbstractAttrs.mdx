Additional abstract attributes of a class. If the class is not abstract, this collection will fall back to `None`.

## Fields

| Name | Type | Required | <center>Description</center> |
| :-----: | :-----: | :-----: | :------ |
| `methods` | `list[DocFunction]` | | The list of abstract methods of this class. |
| `properties` | `list[DocProp]` | | The list of abstract properties of this class. |
| `operators` | `list[DocOpTemplate]` | | The list of abstract operators of this class. |
